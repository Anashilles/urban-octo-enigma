# Assets and licences

Our Museum ships **no third-party 3D models, textures, photographs or audio
files**. Everything visual or audible is generated by this project's own code,
so there is nothing to attribute and nothing copyrighted bundled.

## Generated in code

| What | Where | How |
| --- | --- | --- |
| Architecture (walls, doorways, floors, ceilings, beams) | `src/three/rooms` | Built from template geometry in `src/features/museums/templates.ts` |
| Decor (benches, plants, pedestals, abstract sculptures) | `src/three/rooms/Decor.tsx` | three.js primitives |
| Materials (wood, marble, plaster, concrete, fabric) | `src/three/materials/textures.ts` | Painted on `<canvas>` at runtime with seeded noise |
| Picture frames, mats and plaques | `src/three/frames` | Procedural geometry and materials |
| Avatars and animations | `src/three/avatars` | Procedural 19-joint rig; idle/walk/run/turn/wave clips computed in code |
| Demo artworks (`/demo`) | `src/three/loaders/sample-art.ts` | Abstract paintings drawn on canvas, labelled as samples |
| Seed artworks (`npm run db:seed`) | `prisma/seed.ts` | SVG landscapes/patterns generated in code and processed like uploads; no real photographs |
| Ambient soundscape | `src/features/audio/ambient.ts` | Web Audio oscillators and a synthetic reverb impulse; no recordings |
| App icon | `src/app/icon.svg` | Original vector |

User photos are the only images that appear in a museum besides these
samples. They are never replaced, enhanced or generated by AI.

## Adding assets

If you add models, textures, sounds or fonts:

1. Use only material you created or that carries a licence permitting your use
   (CC0 / CC-BY / OFL and similar), and record the source, author and licence
   in this file.
2. Prefer compressed formats (glTF with Draco/meshopt, KTX2 textures, Opus
   audio) and keep them out of the initial page load.
3. Never add real people's photographs to seeds, demos or tests.
