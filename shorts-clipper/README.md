# صانع المقاطع القصيرة من البث المباشر

أداة تبحث في بث مباشر على يوتيوب عن **اللحظات الجميلة والمؤثرة**، ثم تقصّها
تلقائياً إلى مقاطع قصيرة عمودية (1080×1920) تصلح لـ YouTube Shorts وTikTok وReels.

## كيف تجد اللحظات المؤثرة؟

1. **دردشة البث (Live chat replay):** بعد كل مشهد مؤثر تمتلئ الدردشة بعد ثوانٍ
   برسائل مثل `😭` و`🥺` و`💔` و"crying" و"beautiful" و"goosebumps" و"مؤثر" و"F".
   تقسّم الأداة البث إلى شرائح مدة كل منها 5 ثوانٍ، وتعطي كل شريحة نقاطاً بحسب:
   - نسبة الرسائل العاطفية فيها.
   - مقدار ارتفاع سرعة الدردشة عن معدلها الطبيعي في تلك الفترة.
2. **منحنى "الأكثر إعادة" (Most replayed)** من يوتيوب، إن وُجد.
3. تُستبعد القفزات التي تخلو من أي عاطفة، مثل الصراخ والحماس و"LETS GOOO"،
   لأنها ليست لحظات مؤثرة.

يبدأ كل مقطع قبل تفاعل الدردشة بـ 45 ثانية حتى يظهر المشهد نفسه، وينتهي بعده
بـ 12 ثانية، فتكون مدته نحو 57 ثانية. يحصل كل مقطع على تلاشٍ ناعم في بدايته
ونهايته، ويُضبط مستوى صوته على ‎-14 LUFS، ويُرفق بصورة مصغّرة.

## التثبيت (مرة واحدة)

```bash
# 1) Python 3.9+ و ffmpeg
#    Windows:  winget install Gyan.FFmpeg
#    macOS:    brew install ffmpeg
#    Linux:    sudo apt install ffmpeg

# 2) yt-dlp
pip install -U "yt-dlp[default]"

# 3) يحتاج yt-dlp إلى محرّك JavaScript ليعمل مع يوتيوب. يكفي Deno أو Node.js
#    Windows:  winget install DenoLand.Deno
#    macOS:    brew install deno
```

## الاستخدام

```bash
cd shorts-clipper

# (موصى به) الخطوة الأولى: استعرض اللحظات من دون تنزيل أي فيديو
python make_shorts.py "https://www.youtube.com/live/cWPhAshHWk4" --analyze-only

# الخطوة الثانية: قصّ أفضل 8 لحظات إلى مقاطع عمودية
python make_shorts.py "https://www.youtube.com/live/cWPhAshHWk4"
```

تُحفظ النتائج في مجلد `shorts_out/`:

| الملف | المحتوى |
|---|---|
| `01_1-02-10.mp4` … | المقاطع القصيرة. يدل الرقم في الاسم على وقت بداية المقطع في البث |
| `01_1-02-10.jpg` … | صورة مصغّرة من لحظة الذروة |
| `moments.md` | جدول باللحظات وروابط تفتح البث عند كل لحظة، مع عينة مما كتبته الدردشة |
| `moments.json` | البيانات نفسها بصيغة JSON |

> تنزّل الأداة **الأجزاء المطلوبة فقط** من البث، لا البث كاملاً.
> أما الدردشة فقد يستغرق تنزيلها بضع دقائق إذا كان البث طويلاً (8 ساعات أو أكثر).

## خيارات مفيدة

| الخيار | الوظيفة | الافتراضي |
|---|---|---|
| `-n 12` | عدد المقاطع | 8 |
| `--pre 50 --post 15` | عدد الثواني قبل ذروة التفاعل وبعدها | 45 / 12 |
| `--max-len 90` | أقصى طول للمقطع بالثواني | 60 |
| `--min-gap 300` | أقل مسافة بين مقطعين بالثواني | 240 |
| `--min-emotion 0.3` | يرفع حدّ "العاطفة"، فلا تبقى إلا اللحظات المؤثرة جداً. القيمة 0 تُبقي لحظات الحماس أيضاً | 0.2 |
| `--layout crop` | قصّ منتصف الصورة بنسبة 9:16 بدلاً من الخلفية الضبابية | `blur` |
| `--layout landscape` | الإبقاء على النسبة الأفقية 16:9 | |
| `--timestamps "1:02:10-1:02:58, 3:15:00-3:15:45"` | قصّ أوقات تحددها أنت بنفسك | |
| `--video stream.mp4` | استخدام نسخة من البث نزّلتها مسبقاً | |
| `--no-chat` | الاعتماد على منحنى "الأكثر إعادة" فقط، وهو أسرع | |

## ملاحظات

- لا تتوفر إعادة الدردشة ولا منحنى "الأكثر إعادة" إلا **بعد انتهاء البث**
  وانتهاء يوتيوب من معالجته. إذا كان البث ما زال مباشراً، فشغّل الأداة لاحقاً.
- إذا ظهرت لك رسالة `Sign in to confirm you're not a bot` على جهازك، فيمكنك
  تمرير ملفات تعريف الارتباط (cookies) من متصفحك عبر الخيارين
  `--yt-dlp-arg=--cookies-from-browser --yt-dlp-arg=chrome`.
  يُفضّل استخدام حساب ثانوي، لأن يوتيوب قد يقيّد الحسابات التي تُستخدم مع أدوات التنزيل.
- البث ملك لصاحب القناة (KreekCraft)، ومحتوى اللعبة ملك Rockstar Games.
  إذا أردت إعادة نشر المقاطع، فاذكر المصدر وتأكد من سياسة القناة في ما يخص المقاطع المقتطعة.
